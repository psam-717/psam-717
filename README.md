## 🚀 Featured Projects

### 🏫 [MyEasySchool](https://myeasyschool.org/)
**A learning platform for university students** — enabling access to university-specific learning materials, scheduling weekly study sessions, and maintaining motivation through streaks and XP.  
The platform supports **students**, **collaborators** (who upload content), and **admins**, creating a dynamic academic ecosystem.

> 🧩 **Role:** Backend Engineer  
> 🧠 **API:** Designed and implemented a robust RESTful API with modular architecture and layered access (students, collaborators, admins).  
> 🔒 **Includes both user and admin routes** with JWT-based authentication and subscription verification.

#### 🛠 Tech Stack
Node.js | Express.js | TypeScript | MongoDB (Mongoose) | JWT | Nodemailer | Paystack API | Node-cron

#### 🚀 Key Features
- **🔐 Authentication**
  - Email + OTP verification for student & collaborator registration  
  - JWT-based sessions and Google OAuth2 support  
- **🧑‍🎓 Student Module**
  - Register, select university, and subscribe via **Paystack**  
  - Weekly study scheduler and daily reminder emails  
  - Tracks streaks, XP, and provides access to verified content  
- **🧑‍🏫 Collaborator Module**
  - Register with university and role  
  - Upload subject/topic-based content pending admin approval  
- **🛡 Admin Module**
  - Approve collaborators & uploaded content  
  - Manage streak leaderboards and monitor platform activity  
- **💳 Payments**
  - Subscription handling through **Paystack webhooks**  
  - Verifies transactions and updates subscription status  
- **📬 Email & Scheduling**
  - OTP emails, daily reminders, and weekly XP resets via **cron jobs**

The platform is designed to make car rentals effortless for users while empowering business owners to manage fleets and bookings efficiently.

> 🧩 **Role:** Backend Engineer  
> 🧱 Designed the API architecture and implemented secure, scalable backend logic with Stripe payment integration.  
> 👥 Collaborated with a cross-functional team of developers, designers, and a product manager.

#### ✅ Features (MVP)
- **Car Inventory & Search:** Filter cars by make, model, type, price, and availability  
- **Reservation System:** Guest and user bookings with conflict handling  
- **User Accounts:** Sign up, manage profile, and payment methods  
- **Payment Processing:** **Stripe/PayPal integration** for deposits and rental fees  
- **Booking Management:** Modify, cancel, and view reservations with notifications  
- **Business Dashboard:** Manage cars, reservations, and analytics reports
